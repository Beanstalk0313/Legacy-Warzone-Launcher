# The Legacy Modern Warfare III Launcher (previously Legacy Warzone Launcher) and its backend has been terminated

Due to the release of the Lumen project, the Project HiNAtyu mod for Call of Duty: Modern Warfare III is no longer the best way to play Warzone III.

The Supabase backend has been deleted, meaning all users, profiles, servers, etc. are terminated permanently, and, unless you intend to use this project as a base for something else, the Legacy Modern Warfare III Launcher is officially dead.

Project Lumen is able to do many of the same things that were found in this project, only without the need for an external application or buggy cbuf calls, making it the superior way to enjoy Warzone III. 

This project was never meant to be a permanent solution; it was simply meant to be something to make the HiNAtyu mod easier to use while we waited for Lumen's release (though, it must be admitted, I never thought it would actually release; they have disgusting management over there)
